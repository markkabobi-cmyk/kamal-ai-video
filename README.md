# KAMAL AI — Pro Video Studio

تطبيق توليد فيديو بالذكاء الاصطناعي باستخدام fal.ai (نموذج Wan 2.5).

## الإصلاحات التي تمت

1. **مفتاح API** أصبح يُرسل من الواجهة إلى السيرفر (أو من متغير البيئة `FAL_KEY`).
2. **المدة** محدودة بـ 5 أو 10 ثوانٍ فقط (حد النموذج).
3. **الدقة** محدودة بـ 480p / 720p / 1080p.
4. **الـ Negative Prompt** و **Seed** يعملان في كلا الوضعين (نص وصورة).
5. خيارات الستايل والكاميرا واللباس تُضاف تلقائياً إلى الـ prompt.

## التشغيل

```bash
npm install
# اختياري: export FAL_KEY="your_key_here"
npm start
```

ثم افتح http://localhost:3000

كلمة المرور الافتراضية: `DzVideo2026!`

## ملاحظات

- تحتاج رصيد في حساب fal.ai.
- التوليد يستغرق عادة 30–90 ثانية.
- لا تشارك مفتاحك علناً. الأفضل ضبطه كمتغير بيئة على السيرفر.
